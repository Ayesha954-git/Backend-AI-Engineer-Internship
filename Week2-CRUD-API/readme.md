📌 Week 2 - Task CRUD API

A simple CRUD API built with FastAPI that allows users to create, read, update, and delete tasks. This project was developed as part of the Backend AI Engineering Internship – Week 2 assignment to gain hands-on experience with API development using Python and FastAPI.

🚀 Features

- Create a new task
- Retrieve all tasks
- Retrieve a task by ID
- Update an existing task
- Delete a task
- Automatic API documentation with Swagger UI
- Input validation using Pydantic
- Proper HTTP status codes and exception handling

🛠️ Tech Stack

- Python 3.x
- FastAPI
- Uvicorn
- Pydantic
